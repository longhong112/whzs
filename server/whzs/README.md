# 微话助手授权后台（zb.lhuq.cn/whzs/）

## 组成

| 文件 | 作用 |
| --- | --- |
| `api.php` | App 调用的加密接口，地址固定为 `https://zb.lhuq.cn/whzs/api.php` |
| `admin.php` | 管理后台：登录、批量生成、搜索、禁用、解绑、延期、删除、导出 |
| `lib.php` | 数据库、建表、RSA/AES 加解密、授权签发 |
| `config.php` | 数据库账号、管理员密码、激活码前缀 |
| `schema.sql` | 手动建表用（`lib.php` 也会自动建表） |
| `keys/private.pem` | RSA 私钥，**只放服务器，绝不能公开或提交到仓库** |
| `keys/public.pem` | 公钥，已同时写入 App 源码，可留作备份 |

## 环境要求

- PHP 7.4+，扩展：`pdo_mysql`、`openssl`
- MySQL 5.7+ / MariaDB 10.3+
- 已配置 HTTPS 证书（App 使用 `https://zb.lhuq.cn`）

## 部署步骤

1. 在主机面板创建数据库（字符集 `utf8mb4`），并创建同名数据库用户。
2. 将本目录全部文件上传到网站根目录下的 `whzs/` 文件夹。
3. 修改 `config.php`：
   - `db` 四项改成实际数据库信息；
   - `admin_password` 改成强密码（也可填 `password_hash()` 生成的 bcrypt 串）；
   - `code_prefix` 默认 `LH`，与 App 显示的格式一致。
4. 确认 `keys/private.pem` 已上传，并设置权限 `600`（仅 Web 用户可读）。
5. 浏览器打开 `https://zb.lhuq.cn/whzs/admin.php`，用 `config.php` 里的账号密码登录。
6. 在后台点击「生成」，得到形如 `LH-7K3M-9Q2P-XY8D` 的激活码。

首次访问会自动建表。若主机不支持自动建表，可手动导入 `schema.sql`。

## 已内置的安全措施

- 传输：RSA-2048（OAEP）包裹随机会话密钥 + AES-256-GCM 加密全部请求与响应，抓包只能看到密文。
- 授权串：由服务器私钥签名，App 只内置公钥；本地可离线验签，改配置文件无法伪造授权。
- 一机一码：激活码首次激活时绑定设备，换设备会被拒绝；后台可解绑。
- 后台控制：禁用激活码后，设备在 App 内点「刷新授权状态」即会失效；到期时间也可在后台延长。
- 防重放：请求带时间戳与一次性随机数，超过 5 分钟或重复使用会被拒绝。
- 防爆破：同一设备/IP 10 分钟内失败 10 次会被暂时拒绝；后台登录连续失败 5 次锁定 10 分钟。
- 后台使用会话 + CSRF 令牌，所有数据库操作均使用预处理语句。

## 注意

- 重新运行 `tools/license-keys.ps1` 会生成新密钥，**所有已发出的激活码和已激活用户都会失效**，且需要重新编译 APK。仅在泄露或首次部署时使用。
- Nginx 用户请在站点配置中额外拒绝 `config.php`、`lib.php`、`keys/` 的直接访问，例如：

```nginx
location ~ ^/whzs/(config|lib|schema)\.php$ { deny all; }
location ^~ /whzs/keys/ { deny all; }
```

- 后台的「删除」不可恢复；只想停用请用「禁用」。

## 自测

1. 后台生成 1 个 30 天激活码。
2. App 设置页 →「激活」→ 输入激活码 → 应提示激活成功并显示到期时间。
3. 换一台手机输入同一个码 → 应提示「已绑定其他设备」。
4. 后台点「禁用」→ App 点「刷新授权状态」→ 提示授权已取消，高级功能暂停。
