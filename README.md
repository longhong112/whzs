**微信里的聊天分析、回复建议与话题助手**

微话助手以 LSPosed / Xposed 模块的形式工作在微信进程内：在你浏览聊天时，把上下文交给模型分析，在消息气泡下方给出**语义解读、真实意图与下一步建议**；需要回应时再打开「帮我回 · 找话题」，拿到几条可以直接用的话。

它只做两件事：**让你看明白，让你回得出来**。所有回复都由你确认后手动发送，模块从不自动发消息、不代你说话。

## 功能总览

| 能力 | 说明 |
| --- | --- |
| 聊天分析 | 结合前文、发送人与时间间隔，输出情绪概率、事件解读与可能的潜台词，不伪造自由文本 |
| 意图解析 | 两条线路：决策模型给出概率化判断；智能模型补充文字级意图与「可能在意的点」 |
| 帮我回 | 按对方身份、关系与补充想法生成 1–6 条连续短消息，通常 1–3 条，可直接复制或填入输入框 |
| 找话题 | 一次生成 5 个独立话题，逐个展示 1–3 句口语短消息，结合日期、节日、农历与你的补充资料 |
| 角色库 | 自定义角色、语气与背景，按联系人绑定；对话中即时生效，两端编辑同一份资料 |
| 语音理解 | 语音消息自动转写后参与分析，与文字消息走同一条上下文链路 |
| 提示词自定义 | 分析、回复、话题的提示词逐项可改，立即生效，随时可恢复默认 |
| 自动分析开关 | 按联系人或群聊记忆，默认关闭；关闭后仍可长按消息单独分析 |
| 授权体系 | 一机一码、按天授权，RSA 签名离线校验，后台可禁用、解绑、续期 |

核心原则：**提供证据，不替你决定**。每条解读与建议都标注为参考，不自动发送、不读取你不愿意分享的聊天。

## 界面与入口

设置页采用四个页签，底部固定，随时切换：

| 页签 | 内容 |
| --- | --- |
| 聊天分析 | 模型服务登录、分析开关、保留条数、提示词；共享目录与权限状态 |
| 回复与话题 | 角色库管理：新建、编辑、删除角色与背景 |
| 激活 | 授权状态、激活码、到期时间、设备编号、刷新授权 |
| 关于 | 版本、使用教程、数据与诊断、版权与联系方式 |

微信内的入口：

- **长按对方文字消息** → 分析这段对话 / 帮我回
- **长按自己的消息** → 复盘我的回复
- 展开聊天「＋」面板 → **帮我回 · 找话题** 横条（左侧为「分析」开关）
- 长按「＋」上的分析开关 → 聊天分析（自定义历史条数）、帮我回 / 找话题、微话助手设置、导出运行日志
- 微信设置 →「插件」分组 → 微话助手设置

## 安装与启用

1. 安装 `app-release.apk`，先从桌面打开一次「微话助手」，完成初始化并授予存储权限。
2. 打开 LSPosed → 模块 → 启用「微话助手」→ 作用域勾选**微信**。
3. 彻底结束微信进程（从最近任务划掉，而不是返回桌面），再重新打开微信。
4. 回到微话助手设置页，确认「微信进程状态」显示已连接；未连接时按页面提示排查。
5. 在「聊天分析」页登录 WorkBuddy，或切换到自定义 API 填写接口地址与 Key，点击「测试连接」。
6. 在「激活」页填写激活码。激活成功后即可在微信中使用全部分析与回复功能。

## 使用指南

### 聊天分析

打开与某人的聊天，展开「＋」面板，将左侧的「分析」开关打开（该开关按联系人或群聊记忆）。之后对方发来的文字消息下方会出现分析卡片：

- 首行显示情绪概率，圆环内是百分比，旁边是情绪名称
- 解读与建议分条展示，每条都是短句，没有可靠选择时不会硬凑
- 卡片内容只在你打开该会话时读取，离开或重绑即清理

不想开自动分析也没关系：**长按任意一条对方消息**，选择「分析这段对话」，单条分析同样可用；长按自己的消息则可以复盘当时的回复。

### 帮我回 · 找话题

在聊天「＋」面板点击「帮我回 · 找话题」，抽屉会：

1. 在本机预读当前聊天最近最多 100 条文字记录（上限 48,000 字符），读取期间不能生成
2. 由你选择对方身份、参考条数（30 / 50 / 100），填写本次补充想法
3. 点击生成，得到 1–6 条连续短消息，通常 1–3 条
4. 逐条复制，或点击直接填入微信输入框——**仍然由你按下发送**

「找找话题」则一次给出 5 个独立话题，每个话题就是 1–3 句能直接说出口的话；随机不重复切换，用完后自动请求下一组。改变身份、条数、背景或草稿后，旧建议会失效并重新生成。

### 角色与背景

「回复与话题」页可新建角色：名称、语气、关系与背景。角色按联系人绑定，同一份资料在设置页和聊天抽屉两端编辑，保存后即时生效。修改角色会让旧背景缓存与在途结果失效，避免拿到过期内容。

### 诊断

设置页右上角「运行日志」可查看并导出诊断信息，用于排查注入失败、接口错误或解析异常。日志不会输出完整 API Key。

## 激活与授权

授权采用**服务端签发的授权串**：App 只内置 RSA 公钥，可离线验签，因此修改本地配置文件无法伪造授权。

| 机制 | 实现 |
| --- | --- |
| 一机一码 | 激活码首次激活即绑定当前设备，换机使用会被拒绝，后台可解绑 |
| 按天授权 | 首次激活时按激活码天数计算到期时间，到期后高级功能暂停 |
| 离线可用 | 激活成功后不依赖网络，到期前本地即可校验 |
| 后台可控 | 管理员可随时禁用、延期（+30 天）、解绑或删除 |
| 传输加密 | RSA-2048（OAEP）包裹随机会话密钥 + AES-256-GCM 加密全部请求与响应 |
| 防重放 | 请求带时间戳与一次性 nonce，超过 5 分钟或重复请求直接拒绝 |
| 防爆破 | 同设备 / IP 10 分钟内失败 10 次暂时拒绝；后台登录失败 5 次锁定 10 分钟 |

接口固定为 `https://zb.lhuq.cn/whzs/api.php`，后台入口为 `https://zb.lhuq.cn/whzs/admin.php`。服务端代码、部署步骤与自测流程见 [server/whzs/README.md](server/whzs/README.md)。

未激活时：自动分析与自动回复直接跳过；手动分析提示「请先在设置页「激活」中填写激活码」；「帮我回」在生成前拦截。

> 重新生成密钥（`tools/license-keys.ps1`）会使所有已发出的激活码失效，并且必须重新编译 APK。仅在首次部署或私钥泄露时使用。

## 构建与发版

环境：**JDK 21**、Android SDK **Platform 35**、Gradle **8.9**。仓库不提交 Gradle Wrapper，由 `tools/gradle.ps1` 首次运行自动下载并缓存；脚本顶部的 `JDK`、`Gradle` 路径可按本机情况修改。

```powershell
# 1. 升版本（version.properties 是唯一版本来源）
powershell -File tools/bump-version.ps1            # 补丁号 +1
powershell -File tools/bump-version.ps1 -Part minor # 功能批次 +1

# 2. Debug 构建（日常验证）
powershell -File tools/gradle.ps1 :app:assembleDebug --no-daemon "-Pkotlin.compiler.execution.strategy=in-process"

# 3. Release 构建（签名需要根目录 keystore.properties）
powershell -File tools/gradle.ps1 :app:assembleRelease --no-daemon "-Pkotlin.compiler.execution.strategy=in-process"
```

- 签名配置读取根目录 `keystore.properties`（`storeFile` / `storePassword` / `keyAlias` / `keyPassword`），缺失时 release 包为未签名。
- 构建产物位于 `app/build/outputs/apk/release/app-release.apk`，版本信息见同目录 `output-metadata.json`。
- 每次提交必须同时推进 `versionName` 与 `versionCode`；`git config core.hooksPath .githooks` 可启用提交前校验。
- 应用内版本号一律来自生成的 `BuildConfig`，不硬编码版本字符串。

## 数据与隐私

- 配置与分析缓存位于共享目录 `/Android/media/com.tencent.mm/lh`，设置页与模块进程共用；卸载应用后残留文件可手动删除。
- 消息片段只会发送到**你自行登录或配置的模型服务**，不经过任何第三方中转。
- API Key 默认掩码显示，不写入状态文字与日志。
- 模块不自动上传聊天记录、不自动发送消息，也不会替你点击发送按钮。
- 分析结果只按会话保存在本机，退出聊天即清理卡片视图。

## 常见问题

**装好了，微信里没有任何变化？**
确认 LSPosed 中模块已启用、作用域勾选微信，并**彻底结束微信进程**后重开。仍无效时打开设置页查看「微信进程状态」与运行日志。

**分析卡片不出现？**
检查当前会话的「分析」开关是否打开（默认关闭），以及模型服务是否已登录、测试连接是否通过。长按消息单独分析不依赖自动开关。

**提示「请先在设置页「激活」中填写激活码」？**
说明本地授权不存在或已失效：到设置页「激活」页签填写激活码，或点「刷新授权状态」同步后台状态。

**换了手机还能用同一个码吗？**
不能。一机一码，首次激活即绑定设备。需要换机请联系管理员在后台解绑，再在新设备激活。

**Android 11+ 提示目录不可访问？**
去系统设置授予「所有文件访问」权限，或在设置页点击权限入口跳转授权后重试。

**后台禁用后多久生效？**
本地已有授权在到期前仍可离线使用；在设置页点「刷新授权状态」会立即向后台确认，被取消后清空本地授权。
